# Crypto Intelligence Terminal V2 — Release 0.5.0

Release 0.5 turns the application from a market dashboard into a broader research terminal.

## New modules

- Market Briefing
- Conviction Engine
- DeFi Intelligence powered by DeFiLlama
- Risk-adjusted research rankings
- DeFi protocol, sector and chain leadership tables
- Expanded developer diagnostics

## Existing modules retained

- Dashboard
- What's Hot Now
- Opportunity Scanner
- Portfolio Intelligence
- Developer Status

## Upload

Extract the ZIP and upload every item inside the extracted folder to the repository root, replacing existing files.

The theme remains embedded in Python, so no hidden `.streamlit` folder is required.

## Entry point

`app.py`
